# Z80

See [the assemblers overview](README.md) for the shared source syntax,
expressions and directives (`ORG`, `EQU`, `DB`, `IF`, and so on) — this page
covers only what's specific to the Z80.

## Menu

| Command | Does |
|---|---|
| **Z80 Assembler → Compile** | Saves a ZX Spectrum `.tap` with an auto-running BASIC loader. |
| **Z80 Assembler → Compile and Run** | Saves the same `.tap`, then opens it with its Windows-associated application (such as a Spectrum emulator). |
| **Z80 Assembler → Configure Emulator...** | Selects a specific emulator executable and optional arguments for Compile and Run instead; the quoted TAP path is appended as the final argument. |

Default `ORG`: `$8000`.

## Instruction set

The documented Z80 instruction set, plus `SLL`/`SL1`, `IXH`, `IXL`, `IYH`,
`IYL`, `IN (C)`, `IN F,(C)` and indexed `CB` operations with a register
destination (`RLC (IX+d),B` and the like).

**Supports:** the full documented instruction set and the common
undocumented extras above.
**Does not support:** nothing from the documented or commonly-used
undocumented set — this is the one assembler here with no deliberate gaps.

## Compile

Saves a TAP: a tokenized BASIC loader followed by the code. For code above
Spectrum BASIC memory the loader lowers RAMTOP with `CLEAR`, then loads the
code and calls the entry point (`ENTRY`/`END`, otherwise the first byte).

## Example

`examples/z80-hello.asm` — open it and use **Compile**, then run the saved
`.tap` with `LOAD ""`.
