# Game Boy (SM83)

See [the assemblers overview](README.md) for the shared source syntax,
expressions and directives (`ORG`, `EQU`, `DB`, `IF`, and so on) — this page
covers only what's specific to the Game Boy.

## Menu

| Command | Does |
|---|---|
| **Game Boy Assembler → Compile ROM** | Saves a 32 KB `.gb` cartridge ROM with its header filled in. |

Default `ORG`: `$0150`.

## Instruction set

The Game Boy's SM83 is a cut-down Z80. Its instructions are the Z80's
without IX/IY, `EX`, `EXX`, `DJNZ`, `IN`/`OUT`, the block instructions and
the PO/PE/P/M conditions, which are reported as errors, plus these of its
own:

| Write | Does |
|---|---|
| `LD A,(HL+)` / `LD (HL-),A` | Load and step HL. `(HLI)`/`(HLD)` and `LDI`/`LDD` are the same. |
| `LDH (n),A` / `LDH A,(n)` | The `$FF00`-`$FFFF` I/O page; `n` can be the full address or its low byte. |
| `LDH (C),A` / `LD A,(C)` | `$FF00+C`. |
| `LD HL,SP+e` / `ADD SP,e` | SP plus a signed byte. |
| `LD (nn),SP` | Stores SP. |
| `SWAP r`, `STOP`, `RETI` | Swap nibbles; stop the CPU; return from an interrupt. |

Memory operands can be written with brackets, `LD A,[HL+]`, as in RGBDS
sources, as well as with parentheses. Only A loads from or to an address:
`LD HL,(nn)` is reported rather than read as `LD HL,nn`.

**Supports:** the Z80 subset the hardware actually has, plus the SM83-only
forms above.
**Does not support:** `IX`/`IY` and everything built on them, `EX`, `EXX`,
`DJNZ`, `IN`/`OUT` and the I/O port instructions, the Z80 block instructions
(`LDIR`/`LDDR`/`CPIR`/`CPDR`/…; `LDI`/`LDD` are repurposed above instead),
`IM`, `NEG`, `RETN`, and the `PO`/`PE`/`P`/`M` conditions. Each is reported
as an error rather than silently misencoded.

## Compile

Saves a 32 KB cartridge with no memory bank controller, which every emulator
and flash cartridge runs. Tinker Editor writes the header at `$0100`-`$014F`
itself: `NOP` and `JP` to the entry point (`ENTRY`/`END`, otherwise the
first byte of code), the Nintendo logo the boot ROM checks, a title from the
file name, and both checksums. So code starts at `$0150`; `ORG $0000` first
puts code in the RST and interrupt vectors (the gap to `$0150` is left for
the header). Code in the header, or past `$7FFF`, is reported.

## Example

`examples/gb-hello.asm` — open it and use **Compile ROM**, then run the
saved `.gb` in an emulator such as SameBoy, BGB or mGBA.
